# Документация по функции катапультирования в моде Yak-3s9

Этот документ описывает файлы и скрипты, отвечающие за функцию катапультирования в самолете Як-3с9.

## 1. Активация катапультирования (ввод)

За назначение клавиш для катапультирования отвечает файл `Input/keyboard/default.lua`.

**Файл:** `Yak-3s9/Input/keyboard/default.lua`

**Ключевой скрипт:**
```lua
{combos = defaultDeviceAssignmentFor("plane_eject"), 			down = iCommandPlaneEject, name = _('Bailout'), category = _('Systems')},
```
**Описание:**
Эта строка определяет, что для катапультирования (Bailout) используется стандартная команда DCS `iCommandPlaneEject`. Конкретная комбинация клавиш не прописана в моде, а берется из общих настроек управления DCS.

В этом же файле есть закомментированная строка, которая могла бы жестко задать комбинацию `LCtrl + E`, но она неактивна:
```lua
--[[
    ...
    {combos = {{key = 'E', reformers = {'LCtrl'}}}, down = iCommandPlaneEject, name = _('Eject (3 times)'), category = _('Systems')},
    ...
--]]
```

## 2. Параметры катапультирования

Основные параметры, влияющие на поведение катапульты, находятся в главном конфигурационном файле самолета.

**Файл:** `Yak-3s9/Yak-3s9.lua`

**Ключевые параметры (ОБНОВЛЕНО 19.12.2025):**
```lua
ejection_seat_name	 = 0,             -- 0 отключает модель катапультного кресла (для режима Bailout)
ejection_order 		 = 1,
ejection_added_speed = {0,-2,0},      -- Вектор изменен на падение вниз/назад, чтобы убрать эффект ракеты
```
**Описание:**
*   `ejection_seat_name`: Установлено в `0` для имитации ручного покидания самолета (Bailout), характерного для поршневых самолетов Второй мировой.
*   `ejection_added_speed`: Вектор скорости изменен, чтобы пилот "выпадал" из кабины, а не выстреливался вверх.

## 3. Кликабельная кабина (Реализовано)

Реализована работа кликабельной ручки сброса фонаря и покидания самолета.

### 3.1. Определение команды
**Файл:** `Yak-3s9/Cockpit/Scripts/command_defs.lua`
Добавлена новая команда для ручки:
```lua
CPT_EJECT_HANDLE = __counter(),
```

### 3.2. Кликабельный элемент
**Файл:** `Yak-3s9/Cockpit/Scripts/clickabledata.lua`
Настроен элемент PNT_999. Используется устройство `devices.BAILOUT` для корректной обработки скриптом.
```lua
elements["PNT_999"] = default_button("Canopy Jettison Handle", devices.BAILOUT, device_commands.CPT_EJECT_HANDLE, nil, 1.0)
```
*Примечание: Аргумент анимации выставлен в `nil`, так как для рычага пока не определен корректный номер анимации модели.*

### 3.3. Логика работы (Скрипт)
**Файл:** `Yak-3s9/Cockpit/Scripts/Systems/bailout.lua`
Создан скрипт, обрабатывающий нажатие ручки. При активации он:
1. Выполняет команду сброса фонаря (`device_commands.jettison_canopy`).
2. Трижды вызывает команду DCS `iCommandPlaneEject` (83), инициируя процедуру покидания.

**Регистрация скрипта:**
*   В `devices.lua` добавлен ID: `devices["BAILOUT"]`.
*   В `device_init.lua` скрипт подключен: `creators[devices.BAILOUT] = {"avLuaDevice", LockOn_Options.script_path.."Systems/bailout.lua"}`.
